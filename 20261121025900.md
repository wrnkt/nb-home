# Open Links w/ tmux + Ghostty

To open a link inside `tmux` when using Ghostty, hold down `Shift` while clicking.

### The Shortcut:

• macOS: `Cmd + Shift + Click`
• Linux: `Ctrl + Shift + Click`

### Why this happens

When `set -g mouse on` is enabled in your `tmux` configuration, `tmux` captures all standard mouse clicks so you can select panes, resize splits, and scroll. Holding `Shift` tells Ghostty to bypass tmux's mouse capture and handle the click directly at the terminal level, which triggers the URL opener.

### Configuration & Troubleshooting

If holding `Shift` still doesn't open links, check these two settings:

1. Ghostty Config (`~/.config/ghostty/config`)
URL matching is enabled by default, but ensure it hasn't been turned off:

```ini
link-url = true
```ini

2. tmux Config (`~/.tmux.conf`)

If you are clicking OSC 8 hyperlinks (formatted text links generated by modern CLI tools like `ls --hyperlink`, `git`, or `rg`) rather than plain-text URLs, you need to allow passthrough in `tmux` so Ghostty can read the hyperlink escape sequences:

```
set -g allow-passthrough on
```

(Reload your config afterward with `tmux source-file ~/.tmux.conf`)

3. Keyboard-Only Alternative
If you prefer not to use the mouse at all, you can install the `tmux-open` or `extrakto` plugin via TPM (Tmux Plugin Manager) to fuzzy-find and open visible URLs directly from your keyboard.
