# Viewing Markdown in Shell

#### [glow](https://github.com/charmbracelet/glow?utm_source=chatgpt.com)

`glow` renders headings, lists, tables, code blocks, links, blockquotes, etc.
It also supports scrolling.


Usage:
```bash
cat README.md | glow -
```



#### [mdcat](https://github.com/swsnr/mdcat?utm_source=chatgpt.com)

`mdcat` includes hyperlinks and images when the terminal suports it.
I'm pretty sure Alacritty does support those.

```bash
cat README.md | mdcat
```




#### [Python rich Module](https://rich.readthedocs.io/en/latest/introduction.html)

Likely to be installed, can avoid installing more tools with this.

```bash
# heredoc
# NOTE: `python -` consumes the heredoc as the Python program. `sys.stdin` is no longer connected to README.md
cat README.md | python - <<'PY'
from rich.console import Console
from rich.markdown import Markdown
import sys

Console().print(
    Markdown(sys.stdin.read())
)
PY

# small Python script
cat README.md | python -c '
from rich.console import Console
from rich.markdown import Markdown
import sys

markdown = Markdown(sys.stdin.read())
Console().print(markdown)
'

# as a shell function:
mdview() {
    python -c '
from rich.console import Console
from rich.markdown import Markdown
import sys

Console().print(Markdown(sys.stdin.read()))
'
}

cat README.md | mdview
# --- or ---
mdview < README.md

```
