# The `watch` command`

Watch is best for monitoring the update of a command in real time.

```bash
# -n specifies the interval in seconds
watch -n 5 [command]

# the differences flag highlights what changed since the last run
watch --differences -n 10 [command] 
```


I don't think `watch` is able to stop without `<CC-c>`.
These other structures make up for some limitations:

```bash
# pauses 5 seconds between executions; basically a mirror of the first example.
# but there's still no option to quit, unless the`true` predicate is a variable
# manipulated during the loop. I'm not sure how feasable that is.
while true; do
  your_command_here
  sleep 5
done

# This has a built-in stop. We wait 2 seconds but after the range is consumed
# we break out of the look
for i in {1..10}; do
  your_command_here
  sleep 2
done

```
