# LazyVim Surround Reference

```
surround word under cursor -> gsaiw`
surround word under cursor (when it contains punctuation e.g. `foo.bar`) -> gsaiW`
next 3 words -> gsa3w`
Visual selection -> select, then gsa`
Remove backticks around the cursor -> gsd`
Change backticks to quotes -> gsr`"
```

The pattern is `gsa` + a motion or text object + the character to surround with.
Any character works the same way, like `*,` `_`, `"`, or `(`.
