# Github Issue Labels


## Repository Templates

If you are working out of a personal account (or want to standardize existing repository setups), you can create a "template repository".

Create a repository and customize its labels, [issue template] (https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/configuring-issue-templates-for-your-repository), and basic structure.

Go to the repository's Settings and check the box for Template repository.

When creating a future repo, select this template to copy over all of its settings, including the custom labels.

## Setting Organization-Wide Default Issue Labels

If your repositories are hosted under a GitHub Organization, you can define a master list of labels that will automatically generate every time a new repository is created.

1. Go to your Organization settings.
1. In the left sidebar, navigate to Repository > Repository defaults.
1. Add, edit, or delete labels here to create your organization's standard template

## GitHub CLI (gh) 
> You can use scripts with the GitHub CLI to clone labels from an existing repository to a new one.

## Third-Party Tools
>Tools like `github-label-sync`` (an `npm`` package) allow you to define labels in a single JSON file and sync them across any repository using a GitHub Access Token.
