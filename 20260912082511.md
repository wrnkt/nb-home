# TUI File Manager - Midnight Commander

Midnight Commander, or `mc` is a tool that works as a visually-based file manager.

```bash
sudo dnf install mc
```


#### Features
* Navigate directories with the keyboard
* Copy/move files between panes
* Delete and rename files
* Create directories
* View files
* Edit files
* Search
* Archive operations
* FTP/SFTP and other filesystem access depending on configuration
* Shell commands
